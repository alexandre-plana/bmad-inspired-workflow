# Briefs

`analyse-need` écrit `YYYY-MM-DD_HH-mm_brief_<slug>.md` à partir de son template. Le brief précède le plan et décrit le besoin, les contraintes, les arbitrages et les questions restantes.

## Pas d'index dans cette version

Les briefs restent dans ce répertoire sans entrée dans `INDEX.md` ni `index.jsonl`. Le plan les référence via `relatedBrief`, relatif à `documentation/history/`.
