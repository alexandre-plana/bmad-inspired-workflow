# Forme des données

Choisir la forme qui sert la tâche.

| Besoin | Forme |
|---|---|
| valeur exacte | texte/nombre + unité + contexte |
| statut | label textuel + signal sémantique |
| comparaison précise de nombreux attributs | table/matrice |
| objets homogènes denses | table |
| lecture narrative d'objets | liste |
| objets réellement hétérogènes | cards si leur composition le justifie |
| explication courte contextuelle | helper text / tooltip / popover selon importance |
| information importante non bloquante | message inline / banner |
| détail secondaire d'un objet | panel / expandable section |
| options avancées | progressive disclosure |
| historique où la séquence importe | timeline / activity log |
| relations complexes | graphe seulement si la relation est le message |

## Anti-cardification

Ne pas entourer chaque groupe d'une card par défaut. Essayer d'abord espace, alignement, typographie et séparateurs. Une surface encadrée doit représenter une vraie unité mentale ou interactive.
