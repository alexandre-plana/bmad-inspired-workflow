# Anti-patterns

| Anti-pattern | Correction |
|---|---|
| tout au même niveau | P0–P4 + emphase proportionnelle |
| dashboard = grille uniforme de cards | anomalies/décisions → tendances → détail |
| modal pour tout | inline/panel/page selon fréquence et complexité |
| drawer = mini-page | escalader vers page |
| chart décoratif | partir de la question analytique |
| pie avec beaucoup de catégories | barres / 100% stacked |
| KPI sans contexte | cible, variation, période ou benchmark |
| actions seulement en icônes ambiguës | label ou pattern réellement conventionnel |
| erreur seulement après submit | feedback contextuel au bon moment |
| nested modals | même dialogue, retour parent ou changement de surface |
| long scroll dans petite modal | panel/page |
| F/Z pattern appliqué comme grille | construire la hiérarchie depuis la tâche |
| cards pour chaque section | espace/alignment d'abord |
| progressive disclosure qui cache P0/P1 | ne cacher que P2/P3 selon contexte |
